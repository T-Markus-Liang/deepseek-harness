# @deepseek-ai/dsh-client-ui-workbench

[English](README.md) | 中文

Web 工作区工作台：侧边栏浏览器「文件 / 变更」模式背后的只读查阅界面。本包注册三个席位。FilesView 填充 `sidebar.workspaces.files`，提供按层惰性加载（每层一次请求）的文件树（隐藏文件开关、手动刷新，无监听与轮询）。ChangesView 填充 `sidebar.workspaces.changes`，展示工作区全部未提交的 Git 状态，按已暂存 / 未暂存 / 未跟踪分组，头部显示分支与领先/落后计数。PreviewView 填充右侧详情列的 `conversation.details.workspacePreview` 席位：文件以有界、按语言高亮的文本渲染于 `CodeBlock`；变更以旧/新文本渲染于 `DiffBlock`，并提供「暂存区 / 工作区」基准切换。在两个侧边视图中点击文件会调用注入的 `openPreview`，布局 store 承载预览目标，详情列随即显示预览（替代工具详情），直到详情列关闭。

所有对 Host 的读取都经过 runtime 的工作区查阅接口，Host 将其约束在已注册的工作区根目录内（仅限相对路径、隐藏 `.git`、拒绝二进制与超限内容）。所有请求均可中止，被取代的请求绝不会写入视图。浏览器从不接收绝对主机路径，也不存在任何编辑、暂存、提交或丢弃操作。

## 模型体验

无：工作台是纯粹面向用户的查阅界面。它通过专用 RPC 方法读取文件系统与 Git，从不新增模型可见内容、工具或会话事件。

#### KV 缓存影响

无：不改变任何模型请求。

## 已知限制与暂缓工作

- **无实时刷新** —— 文件树与变更状态仅在手动刷新、进入模式或切换工作区时更新；文件监听与后台轮询被明确排除在范围之外。
- **预览依赖已选中的会话** —— 当前工作区由当前会话推导，因此未选中会话时视图显示空态。
- **文本与大小上限固定** —— Host 查阅器的条目数、文本字节与 Git 输出上限不支持按部署配置。
